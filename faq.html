01

거래를 등록하고 필요한 자료를 모읍니다

위탁기업은 새로운 거래 등록에서 신규 약정 준비 또는 기존 약정 등록을 선택합니다. 거래처·품목·원재료와 약정 조건을 입력합니다.

위탁기업

자료명과 확인할 내용을 요청합니다

거래 상세의 자료 요청하기에서 필요한 자료와 기간을 입력합니다. 수탁기업이 제출하면 같은 거래에서 확인합니다.

→
수탁기업

공개 범위를 정하고 제출합니다

자료 등록에서 파일과 공개 범위를 선택합니다. 상대 기업에 보여 줄 자료는 상대 기업에도 공유로 등록한 뒤 공유 자료 제출하기를 누릅니다.

다음 단계: 같은 거래 안에서 제출자료와 합의할 약정 조건을 확인합니다.

02

약정 조건을 확인하고 조정단가를 계산합니다

기준 납품단가·제품당 원재료비·기준지표·조정요건과 주기를 확인합니다. 단가 적용 기준은 거래 약정에 따라 납품일 또는 검수일로 선택합니다.

양사 약정 조건 승인→비교지표·출처 입력→약정 산식 계산→계산 확인 기록·ERP 반영

거래 상세에서 약정 조건 승인을 진행합니다. 양사의 확인이 끝나면 비교지표 값·지표 출처·조정단가 반영일을 입력하고 조정단가 계산·저장을 실행합니다.

다음 단계: 계산한 단가를 ERP 반영용 CSV로 내려받습니다. 정기 계산의 확인 기록은 선택이며, 매번 양사의 재승인을 기다릴 필요는 없습니다.

03

실제 발주·청구에 반영했는지 확인합니다

수탁기업은 청구정보 제출에서 청구단가와 청구서 식별번호를 입력합니다. 위탁기업은 기존 ERP 등에 가격을 반영한 뒤, 발주·청구 반영 확인에서 발주단가와 날짜를 입력합니다. 수탁기업이 제출한 청구단가는 위탁기업이 대신 수정하지 않습니다.

위탁 발주 + 수탁 청구각 기업이 제출한 값
→
적용 기준일과 단가 확인일치 여부 대조

반영일 이후의 거래인지 약정의 날짜 기준으로 확인합니다. 입력 단가가 계산 결과와 다르면 내용을 다시 확인한 뒤 반영 상태를 처리합니다.

다음 단계: 수탁기업의 청구 제출 내역과 위탁기업의 발주 반영 결과를 업무 이력에 연결합니다. 다음 조정 회차를 계산해도 이전 회차를 보존합니다.

04

거래별 자료와 확인 이력을 내려받습니다

자료·증빙 메뉴에서 필요한 거래를 선택합니다. 증빙 목록 내려받기에는 약정 조건, 계산 근거, 열람 가능한 원문 목록과 승인·반영 이력이 포함됩니다.

+
원문 파일

공유 권한에 맞게 개별 확인

원문 파일은 거래 상세의 내려받기로 각각 확인합니다. 제출처의 필수 서류와 최종 제출 범위는 담당자가 확인합니다.

결과: 거래별로 확인한 조건과 자료를 같은 흐름에서 다시 찾을 수 있습니다.

현재 이용 환경

이 로컬 버전은 입력한 거래와 자료를 현재 브라우저에 저장합니다. 별도 기기 간 동기화, 실제 계정 인증, 정부기관 제출은 연결되지 않았습니다. 파일 등록은 보관 기능이며 OCR·AI 분석을 실행하지 않습니다. 실제 기업 기밀자료 대신 인터뷰용 자료로 이용합니다.
