01 — 문제

원가는 올랐고, 조정 업무는 엑셀과 메일에 흩어져 있습니다

  1. 계약은 끝났는데 발주는 계속

    계약 만료 뒤 약정서를 갱신하지 않거나, 단가를 바꾸고 약정서를 다시 발급하지 않은 사례가 직권조사에서 나왔습니다.

  2. 계산은 했는데 반영은 안 됨

    조정단가를 계산해도 다음 달 발주에 옛 단가가 남아 있는지 누군가 다시 대조해야 합니다.

  3. 자료는 매번 처음부터

    공급사는 이미 낸 확인서를 또 요청받고, 제출할 땐 근거 파일과 페이지를 다시 찾습니다.

02 — 쓰는 법

새로 약정하지 않고, 지금 있는 약정에서 시작합니다

  1. 01기존 약정 가져오기

    약정서를 올리면 조건을 찾아 보여줍니다.

  2. 02매달 지표 확인·계산

    요건을 넘으면 약정 산식대로 계산합니다.

  3. 03발주·청구 반영 대조

    옛 단가로 남은 발주를 찾습니다.

  4. 04목적별 제출자료

    목적별로 필요한 자료를 묶습니다.

갱신 기한·조정 시점은 먼저 알려드립니다

  • 이메일

03 — 역할

올리는 사람, 확인하는 사람, 승인하는 사람이 다릅니다

  1. 올림구매 담당자 또는 공급기업

    약정서·발주 파일 등록

  2. 확인상대 기업 담당자

    값과 계산 결과 확인

  3. 승인결재권자 (예: 구매팀장)

    최종 확정 · 기록이 남습니다

  • 계약 종료·단가 변경 뒤 약정 갱신이 필요한 건을 알려줍니다
  • 품목별 인상·인하 예상액과 적용 수량을 미리 봅니다
  • 계산단가와 발주·청구 단가가 다른 건을 찾습니다
  • 미연동 합의도 사유와 서면을 같이 보관합니다

이용료구매기업이 냅니다. 품목·문서량 한도를 미리 정합니다.

  • 요청마다 항목·이유·기간·받는 사람이 적혀 옵니다
  • 이미 낸 유효 자료는 다시 올리지 않고 재사용을 승인합니다
  • 상세 매입자료는 기본 비공개, 공유할 결과만 고릅니다
  • 계산 → 발주 반영 → 청구 → 지급근거까지 내 거래를 확인합니다

이용료기본 무료입니다. 참여 여부를 협력사 평가에 쓰지 않습니다.

  • 요청 항목 → 산출값·집계 기준 → 계약 목록 → 근거 문서 순서로 읽습니다
  • 지갑이나 별도 프로그램 없이 PDF·엑셀과 원문 색인으로 봅니다
  • 체결, 계산, 반영, 지급을 구분하고 중복·취소 건을 뺀 기준을 적습니다

참고실적 인정과 진위 확인은 기관의 업무입니다. 서비스 이용만으로 포상·가점이 생기지 않습니다.

06 — 자주 묻는 질문

자주 묻는 질문

정부 지원을 받지 않은 약정도 쓸 수 있나요?

네. 연동약정은 거래 양사가 맺는 것이고, 매번 정부 승인이나 전문기관 확인서가 필요한 구조가 아닙니다. 양사가 직접 맺은 약정도 그대로 가져옵니다.

연동하지 않기로 한 거래는요?

미연동 합의도 사유와 서면을 남겨야 합니다. 합의서와 사유를 약정 목록에 같이 보관하고, 조사·보고 때 별도로 표기해 묶습니다.

AI가 금액을 정하나요?

아니요. AI는 문서에서 값을 찾고 설명하는 데만 쓰고, 금액은 약정 산식대로 계산 프로그램이 냅니다. 확정은 결재권자가 합니다.

블록체인을 쓰나요?

본 서비스는 일반 서버와 권한 관리로 운영합니다. 승인된 조정 차액을 테스트 토큰으로 지급해 보는 실증은 별도로 진행하며, 서비스 이용에 지갑이 필요하지 않습니다.
